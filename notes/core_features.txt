Core Features

Art Style:
- Pixel art style, inspired by Noita and Cast n Chill

Core Gameplay Loop:
- Dark Souls 3 enemy/boss pacing with Cuphead/Noita/Dead Cells combat
- Characters inspired from things in Bosch and others artwork
- Plunder caves for items/weapons to use in above ground combat

Key Mechanics:
- Physics-based combat and exploration (inspired by Noita).
- Physics-based destruction and simulation (inspired by Noita).
- Idle Progress
- Base Building: Customizable home base
- Itemization: Different items (clothing, cosmetics, decorations) have stats (+/-)
- Inventory: Grid-based / "block" / DayZ style inventory management.
